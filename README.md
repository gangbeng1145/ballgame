================================================================
  丛林滚球 / Jungle Ball
================================================================

  「丛林滚球」
  "Jungle Ball"

----------------------------------------------------------------
  项目介绍 / Project Introduction
----------------------------------------------------------------

  项目简介：
  一个 2D 跑酷小游戏，小球在丛林中滚动前进，跳跃躲避障碍、
  收集金币，速度越来越快。支持键盘与触屏操作，单机即开即用，
  素材全部内嵌，无需联网、无需安装。小球带有弹性形变与滚动
  旋转的物理动画，碰撞判定精准流畅。

  (A 2D endless-runner game where a ball rolls through a jungle,
   jumping over obstacles and collecting coins while speed keeps
   increasing. Supports keyboard & touch input, runs offline with
   all assets embedded - no install needed. The ball features
   squash-and-stretch physics with rolling rotation and precise
   collision detection.)

----------------------------------------------------------------
  使用说明 / Usage
----------------------------------------------------------------

  操作说明：
  - 空格 / ↑ / 点击：跳跃（空中可二次跳跃）
  - ↓：快速落地
  - 收集金币 +25 分，躲避石头 / 尖刺 / 树桩 / 尖刺地面
  - 速度会越来越快，最高分自动保存（浏览器本地）
  本地使用：直接双击 index.html 即可游玩，或可离线运行。

  (Controls: Space / Up / Tap to jump (double-jump in air),
   Down to fast-fall. Collect coins (+25) and dodge rocks,
   spikes, stumps and spike-grounds. Speed ramps up and your
   best score is saved locally. To run: just open index.html -
   works offline.)


----------------------------------------------------------------
  技术栈 / Tech Stack
----------------------------------------------------------------

  所用技术：
  纯 HTML5 + Canvas + JavaScript，无框架、无依赖。素材以
  base64 内嵌，单文件可运行。圆形碰撞检测 + 弹性形变动画。

  (Vanilla HTML5 + Canvas + JavaScript, no framework or
   dependency. Assets embedded as base64. Circle collision
   detection with squash-and-stretch animation.)
