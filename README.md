# 🌴 丛林滚球 (Jungle Ball)

一个 2D 跑酷小游戏：小球在丛林里滚动前进，跳跃躲避障碍、收集金币，速度越来越快。

## 🎮 玩法

- **空格 / ↑ / 点击**：跳跃（空中可二次跳跃）
- **↓**：快速落地
- 收集 **金币**（+25 分）
- 躲避 **石头 / 尖刺 / 树桩 / 尖刺地面**
- 速度会越来越快，**最高分自动保存**（localStorage）

## 🚀 运行

直接打开 `index.html` 即可游玩，单机离线，无需联网，无需安装。

## 📁 文件结构

```
丛林跑酷/
├── index.html   # 主游戏(内含全部逻辑)
├── assets.js    # 图片素材(base64 内嵌)
└── assets/      # 原始 PNG 素材
```

## 🖥️ 技术

- 纯 HTML5 + Canvas，无任何依赖
- 素材全部内嵌 base64，单文件可运行
- 圆形碰撞检测、弹性形变、滚动旋转动画
